## Citation
"1782 Land Taxes Pittsylvania County, Virginia," entry "George Cook Jr ... 100"; web transcription posted 17 Sep 2010 on *My Long Hunters* (https://www.mylonghunters.info/1782-land-taxes-pittsylvania-county-virginia : accessed 28 Nov 2026), which copies http://www.rootsweb.ancestry.com/~vapittsy/1782LandTaxes.htm; attested copy "A Copy Teste / Jos. ## Transcription
Neighbors in list order, verbatim name and acreage: "Daniel Everett 275" / "George Cook Jr 100" / "John Waller 710" / "James Hollaway 97" / "Absalum Hindrick 295". Other Cooks in list: Josiah Cook 130; John Cook 100; Harmon Cook 1052; Joseph Cook 400. No George Cook Sr., no Elijah Cook, no Musick/Music entry.

## Notes
- Derivative web copy of a list with no district named. Order Everett, Cook Jr., Waller matches the order on p. 41 of the 1782 enumeration (S-va-heads-of-families-1782-pittsylvania-p41-cook), which may reflect the same collector's district. Observation only.
- James Hollaway 97 acres: same acreage as DB 6:34-35 (97 ac); noted only because Holloway is in the plan's FAN list. No link established.
