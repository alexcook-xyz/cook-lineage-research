# Security and Privacy Policy

## Report privately
Do **not** open a public issue for the problems below. Use GitHub's private vulnerability reporting ("Security" tab, "Report a vulnerability").

What to report:
- A living person's details (names, birth dates, addresses, relationships) that appear in this repository or its history
- A DNA kit number, match name, or other genetic data of a living person
- Credentials, tokens, or keys committed by mistake
- A vulnerability in the tools in `tools/` or the automation in `.github/`

## What we do
- We acknowledge a report within 7 days and aim to remove exposed personal data within 14 days.
- Removal may need a history rewrite. We will tell you what we did.
- If a credential was exposed, we rotate it; removing it from the repository is not enough.

## Supported versions
Only the latest release and the default branch receive fixes.

## Privacy rules this project follows
Living people and people born less than 100 years ago without a recorded death are not published. DNA data is summarized without names or kit numbers.
